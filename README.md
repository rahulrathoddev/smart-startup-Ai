# Smart Startups: AI Founder Productivity Suite

A glassmorphic Next.js and React frontend styled in obsidian black, neon green, and warm beige. Designed for founders to delegate customer service, talent acquisition, and user interviews to autonomous AI agents connected to internal tools.

## Highlights

- **Black, Neon Green, and Beige Glass UI**: Frosted glass layers, specular borders, ambient background lighting, and fluid transitions built purely with standard CSS.
- **Top Maximize View**: One-click button in the top bar smoothly expands the workspace to full width for distraction-free focus.
- **Three AI Agent Workspaces**: Switch cleanly between Customer Service, Talent Acquisition, and User Interviews.
- **AI Autopilot & Editable Drafts**: Run autopilot on pending queues or expand any task to edit the agent draft before syncing.
- **Priority Tags, Search, Filters & Live Activity**: Queue tasks with priority levels, filter in real time, toggle internal tool syncs, and watch live feedback toasts.

## Tech Stack

- Next.js 16 (App Router)
- React 19
- Standard CSS (zero extra dependencies)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
